# opnsense-sonicwall-networking
Configuration and documentation for multi-site networking with OPNsense and SonicWall, including VLANs, DHCP relay, VPNs, and firewall policies.

## Overview

This repository documents the multi‑site network architecture I built and maintain using **OPNsense** and **SonicWall** firewalls.

### Features

- **VLAN and inter‑VLAN routing:** Logical network segmentation across clinics and offices.
- **DHCP relay and PXE boot:** Centralized DHCP services with relay agents for imaging workflows.
- **Site‑to‑site and remote‑access VPNs:** Secure connectivity between sites and remote users.
- **Firewall policies and NAT rules:** Example rule sets, NAT configurations, and intrusion prevention tuning.
- **High availability:** Redundant firewall pairs and failover strategies to minimize downtime.
- **Configuration backups and deployment scripts:** Tools and scripts for backing up and deploying configuration changes.

Use this repository as a reference for planning, configuring, and managing secure, scalable network infrastructure across multiple sites.
